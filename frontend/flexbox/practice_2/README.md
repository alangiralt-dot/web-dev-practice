# Practice 2: The Full-Screen Centered Card

## 🎯 Goal
Master centering an element both **horizontally** and **vertically** within the entire browser window.

## 🛠 Core Concepts
- `min-height: 100vh`: Ensures the container fills the full screen height.
- `justify-content: center`: Horizontal alignment.
- `align-items: center`: Vertical alignment.

## 📝 Requirements
- Create a container that covers the full viewport.
- Place a card inside that remains centered on all screen sizes.
- Style the card with padding, border-radius, and a box-shadow.
