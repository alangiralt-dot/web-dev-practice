An interface is a strictly professional contract.
While an Abstract Class defines what an object is (inheritance), an Interface defines what an object can do (behavior). It does not provide any tools or code; it only provides a list of requirements.
The "Wall Outlet" Metaphor
Think of a power outlet in your wall.
The outlet is the Interface. It has a specific shape and a rule: "If you want electricity, you must have a plug that fits these three holes."
The outlet doesn't care if the device is a Lamp, a Laptop, or a Toaster.
The Lamp and the Toaster are completely different objects, but they both "implement" the same interface because they both have a plug.
The Key Rules
No Implementation: You cannot write any code inside the methods. You only write the name: public function plugIn();.
Total Commitment: If a class implements an interface, it must define every single method listed in that interface, or the code will crash.
Multiple Contracts: In PHP, a class can only have one "parent" (Abstract Class), but it can sign as many "contracts" (Interfaces) as it wants. For example, a Smartphone could implement Rechargeable, Camera, and WebBrowser.
