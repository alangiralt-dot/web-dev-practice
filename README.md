# Web Dev Practices

Personal collection of small practices to better understand the theory.

## Repository Structure
- **frontend/**: Practices on CSS and HTML.
- **backend/**: Practices on PHP and SQL.

## How to Use
1. **Browse** the category folders to find a practice.
2. **Read** the local `README.md` within that folder for implementation steps.
3. **Copy/Paste** the code.
